# Android wrapper — Generated on demand

This folder is a placeholder. It will be generated by `npx cap add android` after you install Node/Capacitor.

After generation it will contain:
- Gradle wrapper (`gradlew`)
- `app/src/main/assets/public/` ← synced from `../www`
- `AndroidManifest.xml` with Internet + MIDI permissions

Do NOT commit the 99MB media zip in this folder. See `.gitignore`.

Quick regenerate:
```bash
cd TurkishOrganPro
npm install
npx cap add android
npx cap sync
cd android && ./gradlew assembleDebug
```
